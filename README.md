# 📚 List of Basic Sorting Algorithms

Repository này tổng hợp các thuật toán sắp xếp cơ bản được cài đặt bằng JavaScript nhằm mục đích học tập và ôn luyện cấu trúc dữ liệu & giải thuật.

## 🎯 Mục tiêu

- Hiểu nguyên lý hoạt động của các thuật toán sắp xếp.
- So sánh ưu điểm và nhược điểm của từng thuật toán.
- Rèn luyện tư duy giải thuật và kỹ năng lập trình JavaScript.

## 📂 Danh sách thuật toán

### Quick Sort
- Chia để trị (Divide and Conquer).
- Chọn một phần tử làm pivot.
- Phân hoạch mảng thành hai phần và sắp xếp đệ quy.

### Merge Sort
- Chia mảng thành các mảng con nhỏ hơn.
- Sắp xếp và hợp nhất các mảng con.
- Độ phức tạp ổn định: O(n log n).

### Heap Sort
- Sử dụng cấu trúc dữ liệu Heap.
- Xây dựng Max Heap và đưa phần tử lớn nhất về cuối mảng.
- Độ phức tạp: O(n log n).
